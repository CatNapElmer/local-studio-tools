Privacy policy

Last updated: October 24, 2026

Local Studio Tools is a personal program used only by the owner of the Local Studio YouTube channel to manage that one channel. It uses YouTube API Services.

What Google data it accesses

When the owner signs in, the program asks Google for permission to manage the owner's YouTube account (scope youtube.force-ssl). With that permission it reads and changes the channel's own videos, playlists and comments, and reads the channel's public statistics.

How the data is used

The data is used only to show the owner information about their own channel and to make changes the owner asks for. It is not used for advertising, analytics, profiling or training any model.

Storage

The sign-in token is saved in a file on the owner's own PC. Nothing is stored on any server run by this program, because there isn't one. Channel data is fetched from YouTube when needed and is not kept.

Sharing

No data is sold, shared or sent to anyone other than Google's own YouTube API.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, which also makes the saved token stop working.

YouTube and Google

By using this program you agree to the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.
